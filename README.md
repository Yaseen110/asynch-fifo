# Asynchronous FIFO (Dual-Clock, Gray-Code Synchronized)

A parameterized dual-clock FIFO that safely transfers data between two independent clock domains (write clock and read clock) using Gray-coded pointers and two-stage synchronizers to avoid metastability.

## Features

- Configurable data **width** and **depth** via module parameters
- Depth-agnostic address width, computed automatically as `$clog2(depth)`
- Gray-coded read/write pointers with 2-flop synchronizers across clock domains
- `Full` and `Empty` flag generation using the standard MSB-comparison technique
- `Almost Full` / `Almost Empty` status flags for early warning before the FIFO fills or drains
- Combinational (asynchronous) read data output

## File Structure

| File | Module | Description |
|---|---|---|
| `top.v` | `top` | Top-level module; instantiates and connects all submodules |
| `async_fifo.v` | `async_fifo` | Dual-port memory array — write on `wclk`, combinational read |
| `write_logic.v` | `write_logic` | Write pointer generation, write address, `full`/`almost_full` flags |
| `read_logic.v` | `read_logic` | Read pointer generation, read address, `empty`/`almost_empty` flags |
| `sync_w_r.v` | `sync_w_r` | 2-flop synchronizer: synchronizes write pointer into the read clock domain |
| `sync_r_w.v` | `sync_r_w` | 2-flop synchronizer: synchronizes read pointer into the write clock domain |
| `tb.v` | `tb` | Testbench driving the FIFO with write/read stimulus |
| `dump.vcd` | — | Waveform dump generated by simulation |
| `simv` | — | Compiled simulation executable |

## Architecture

```
        wdata ─────────────┐
        winc  ─────────────┤
        wclk  ──┬──────────┤        ┌──────────────┐
        wrst  ──┤   write_logic  ───┤              │
                │  (wptr, waddr,    │  async_fifo  │
                │   wfull, af)      │  (memory)    │───► rdata
                └───────┬───────────┤              │
                        │           └──────┬───────┘
                 ┌──────▼──────┐           │
                 │  sync_w_r   │    ┌──────▼──────┐
                 │ (wptr→rclk) │    │  sync_r_w   │
                 └──────┬──────┘    │ (rptr→wclk) │
                        │           └──────┬──────┘
                        │                  │
        rclk  ──┬───────▼──────────────────▼───┐
        rrst  ──┤        read_logic             │
        rinc  ──┤   (rptr, raddr, rempty, ae)   │
                └────────────────────────────────┘
```

## Top-Level Ports (`top.v`)

| Port | Direction | Width | Description |
|---|---|---|---|
| `wdata` | input | `width` | Write data |
| `winc` | input | 1 | Write enable request |
| `wclk` | input | 1 | Write clock |
| `wrst` | input | 1 | Write-domain reset |
| `rinc` | input | 1 | Read enable request |
| `rclk` | input | 1 | Read clock |
| `rrst` | input | 1 | Read-domain reset |
| `wfull` | output | 1 | FIFO full flag |
| `rempty` | output | 1 | FIFO empty flag |
| `rdata` | output | `width` | Read data |
| `almost_full` | output | 1 | Asserted when FIFO is nearly full |
| `almost_empty` | output | 1 | Asserted when FIFO is nearly empty |

## Parameters

| Parameter | Default | Description |
|---|---|---|
| `width` | 8 | Data bus width |
| `depth` | 10 | Number of FIFO entries (address width derived via `$clog2(depth)`) |

Example instantiation (as used in `tb.v`, overriding defaults):
```verilog
top #(.width(8), .depth(64)) dut (...);
```

## Design Notes

- **Pointer width** is `addr_width + 1` — the extra MSB is the standard technique used to distinguish the full condition from the empty condition when read and write addresses wrap around and become equal.
- **Full/Empty detection**: `full` is asserted when the synchronized read pointer's MSB differs from the write pointer's MSB while the remaining bits match; `empty` is asserted when the synchronized write pointer equals the read pointer exactly.
- **Almost Full / Almost Empty**: computed by converting the synchronized Gray-coded pointer back to binary and comparing the count difference against a threshold.
- **Metastability protection**: both pointers cross clock domains only after Gray-code conversion and pass through a 2-stage flip-flop synchronizer (`sync_w_r`, `sync_r_w`) before being used for flag generation on the opposite clock.

## Running the Simulation

**Using Icarus Verilog:**
```bash
iverilog -o simv async_fifo.v read_logic.v sync_r_w.v sync_w_r.v tb.v top.v write_logic.v
vvp simv
```

**Using Synopsys VCS:**
```bash
vcs async_fifo.v read_logic.v sync_r_w.v sync_w_r.v tb.v top.v write_logic.v -o simv
./simv
```

Both produce `dump.vcd`, which can be viewed with:
```bash
gtkwave dump.vcd
```

## Testbench Behavior (`tb.v`)

- Instantiates the FIFO with `width = 8`, `depth = 64`
- Applies reset, then writes three values (`0x01`, `0x04`, `0x08`) on the write clock
- Issues read pulses on the read clock to pop entries back out
- Dumps all signals to `dump.vcd` for waveform inspection
